## Cricket Umpire Counter App

Code repository for the cricket umpire counter app currently published on the [Google Play Store](https://play.google.com/store/apps/details?id=com.companyname.umpirecounter&pli=1) with over 21k downloads and a 4.2:star: rating as of 8th November 2026.

Code is regularly maintained to keep up with Android requirements, if you would like a new feature, please open an issue to address this.
